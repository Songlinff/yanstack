# 6TB 网盘怎么整理（可执行方案）

你一个人整理不完是正常的。**正确做法不是整理完 6TB**，而是：

> 原盘当「冷库」不动 → 脚本自动打标签 → 只挑几百个精品包上架到网站。

---

## 三层结构（必须接受）

| 层 | 是什么 | 你要做什么 |
|----|--------|------------|
| 冷库 | 现有 6TB 原样保留 | **不要**全量重命名/搬家 |
| 索引层 | 脚本生成的分类清单 | 跑脚本即可 |
| 热库/上架层 | 每科几十个「文件夹商品」 | 只给这些生成网盘分享链接 |

网站永远只挂「热库」，不要试图把 6TB 都变成商品。

---

## 立刻能做的办法

### 方法 A：本机有同步目录（最强）

若百度/阿里客户端把一部分目录同步到电脑：

```bash
cd yanstack
npx tsx scripts/organize-netdisk.ts --scan "D:\你的网盘同步目录"
```

会生成：

- `output/REPORT.md` — 分类统计 + 建议先上架列表  
- `output/featured-candidates.json` — 每类 Top 候选  
- `output/move-plan.json` — 可选搬家建议（默认不执行移动）

### 方法 B：只有网盘网页（无同步）

1. 打开网盘，从根目录开始，**按页复制文件/文件夹名**（可分批）  
2. 粘贴到 `yanstack/input/filelist.txt`（一行一个路径或文件名）  
3. 运行：

```bash
cd yanstack
npx tsx scripts/organize-netdisk.ts
```

文件太多就**先只导出一级、二级文件夹名**，不要导出每一个 PDF。

### 方法 C：找人/找工具导出目录树

用网盘的「导出文件列表」类工具（若有），或请同学帮忙导出目录文本，再交给脚本。

## 上架节奏（一个人也能做完）

1. **第 1 周**：政治/英语/数学 各上 10 个包（共 30）——网站就能用  
2. **第 2 周**：专业课 + 院校 再上 20 个  
3. 其余 6TB 继续躺在冷库，有需要再挑

每个包只做一次：

- 确认是一个文件夹  
- 生成百度 / 阿里 / 夸克 三个分享（或先做百度，另外两个后补）  
- 把「包名 + 链接」发我 → 我写成商品文案并帮你进后台结构

## 为什么不能「全自动整理完 6TB」

- 6TB 含游戏/软件等非考研目录，且全量下载/搬家不现实  
- 考研资料内部大量重复与网课全集，只能**抽样上架 + 按老师/科目拆包**  
- 分享链接必须你在网盘端生成（平台风控，无法代创永久链）
