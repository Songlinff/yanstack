# 后台管理系统 · 20 轮横向优化

对照：dujiao-next Admin、LDC Shop、Ant Design Pro、next-admin、acg-faka 支付后台思路。

| # | 评估问题 | 改进 |
|---|----------|------|
| 1 | 后台混在前台页头里，不像管理系统 | 独立 `AdminShell` 侧栏 + StoreChrome 隐藏前台导航 |
| 2 | 无模块化菜单 | 仪表盘/商品/分类/订单/券/用户/支付/导出/设置 |
| 3 | 仪表盘只有总数 | 今日/近7日/累计成交 + 渠道就绪数 |
| 4 | 无库存预警 | 有限库存 ≤5 预警列表（LDC） |
| 5 | 无热销排行 | TOP5 已售排行 |
| 6 | 订单无独立列表页 | `/admin/orders` 表格 + 状态 Tab |
| 7 | 订单难搜索 | 订单号/邮箱/联系方式搜索 |
| 8 | 无订单详情台 | `/admin/orders/[orderNo]` 全字段 + 支付记录 |
| 9 | 交付内容后台改不了 | AdminDeliveryEditor 改网盘 JSON |
| 10 | 无退款操作 | 标记退款 + 备注（人工记账） |
| 11 | 分类只能 seed | 分类后台 CRUD + 启停 |
| 12 | 用户无法管理 | 用户列表/搜索/拉黑解封 |
| 13 | 被拉黑仍可登录 | auth 校验 `isBlocked` |
| 14 | 支付配置黑盒 | 支付渠道页显示就绪/未配置 |
| 15 | 站点文案改不了 | 设置页：公告/客服微信/邮箱 |
| 16 | 无数据备份出口 | JSON 导出订单/商品/优惠券 |
| 17 | 商品列表简陋 | 表格化 + 搜索 + 库存销量列 |
| 18 | 登录后难回后台 | `?next=/admin` + 默认管理员演示账号 |
| 19 | 移动端后台难用 | 侧栏抽屉 + 遮罩 |
| 20 | 缺文档 | ADMIN.md + 本优化日志 + 缺失配置清单 |

考研特色：科目分类、年份/科目字段、网盘交付编辑、客服微信设置。
