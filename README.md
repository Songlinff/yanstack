# 考研资料网页售卖平台

成品在子目录 **`yanstack/`**（品牌名：**研栈**）。

```bash
cd yanstack
npm install
npm run db:setup
npm run dev
```

打开 http://localhost:3000

请先阅读：
- [yanstack/README.md](yanstack/README.md) — 前台启动与功能
- [yanstack/ADMIN.md](yanstack/ADMIN.md) — **后台管理系统**
- [需要你填写的配置.md](需要你填写的配置.md) — 支付/域名等
- [后台需要你填写.md](后台需要你填写.md) — 后台运营相关补全项

参考项目克隆在 `_refs/`（dujiao-next、digital-marketplace 等），仅供对照，不直接部署。
